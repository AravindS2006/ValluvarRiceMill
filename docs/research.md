## Existing codebase audit

The old site had five static marketing pages, fetched HTML fragments, Bootstrap
and jQuery plugins, obsolete analytics, a Google Translate widget, and a browser
chatbot calling an external API with an embedded credential. Contact validation
did not deliver enquiries. The map pointed outside the client's location.

Twenty-two distinct page/image references were missing. Copy mixed Dharapuram,
Sasaram, placeholder contacts, generic Rice Industries branding, certification
numbers, and unrelated products. Visual inspection found watermarked stock
photography and India Gate packaging. None of those claims or assets were
carried into the redesign.
