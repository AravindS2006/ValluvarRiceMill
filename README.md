# Valluvar — The journey of a grain

A complete English/Tamil redesign for Valluvar brand, Thirumurugan Modern Rice
Mill, Dharapuram. Built with Astro, TypeScript, custom CSS, GSAP, and Three.js.
All pages are rendered as static HTML. The repository includes the GitHub Pages
deployment workflow added by the project owner.

## Run locally

Requires Node.js 22.14+ and npm.

```powershell
npm ci
npm run dev
```

Open the local URL printed by Astro (normally `http://127.0.0.1:4321`).

```powershell
npm run check
npm test
npm run build
npm run verify:site
npm run preview
```

The Astro launcher disables optional CLI telemetry and avoids writing Astro
settings to the user's profile. Dependencies are locked in `package-lock.json`.
Undici stays on its Node 22.14-compatible major for Astro's transitive font utility.

## Structure and behaviour

- `/`, `/mill/`, `/journey/`, `/rice/`, `/gallery/`, `/contact/` and Tamil
  equivalents under `/ta/`.
- `/index.html` continues to be the home document. Legacy `about.html`,
  `products.html`, `gallery.html`, and `contact.html` entry points redirect to
  their replacement pages. Redirects are generated by
  `src/pages/[legacy].html.ts` and respect the configured deployment base.
- `src/data/site.ts` holds the bilingual copy, business configuration, product
  confirmation status, FAQs, and lifecycle chapters.
- `src/data/media.ts` selects real field films for each chapter. The home hero
  has a separately framed portrait video and poster for mobile. Website-ready
  excerpts and their exact source ranges are documented in the media manifest.
- `src/lib/enquiry.ts` validates requirements, prepares bilingual messages,
  and constructs encoded WhatsApp links. It does not send or store enquiries.
- Three.js is loaded only near the journey illustrations. Video is loaded on
  visibility; only one clip plays at a time. Visible muted video autoplays on
  desktop and mobile, using lighter video files on mobile. Reduced motion and
  Save-Data preferences suppress autoplay. Mobile 3D starts on an explicit
  tap. Posters, explanatory text, and stage labels
  remain available if playback or WebGL fails.
- Product dialogs and gallery lightboxes use native HTML dialogs. The 3D grain
  has labelled stage buttons and a keyboard-operable rotation range control.

## Production and review configuration

Local builds default to review mode: `noindex, nofollow`, a blocking robots.txt,
and a preview banner. The GitHub Pages workflow builds in production mode with
`PUBLIC_REVIEW_BUILD=false`, the configured Pages origin, and its project path.
Production pages are indexable and have no preview banner; the 404 and legacy
redirect documents remain noindex. robots.txt and sitemap follow the same base.
CI validates root/project hosting in both review and production modes.

```powershell
$env:SITE_URL = 'https://aravinds2006.github.io'
$env:SITE_BASE_PATH = '/ValluvarRiceMill/'
$env:PUBLIC_REVIEW_BUILD = 'false'
npm run build
npm run verify:site
```

## GitHub Pages paths

The Pages workflow passes its origin and project base from `configure-pages`
through `SITE_URL` and `SITE_BASE_PATH`, and uses Node 22. Navigation, media,
captions, responsive images, legacy redirects, metadata, and the sitemap all
respect the same base. CI checks root and `/ValluvarRiceMill/` in both build modes.

To reproduce the Pages build locally:

```powershell
$env:SITE_URL = 'https://aravinds2006.github.io'
$env:SITE_BASE_PATH = '/ValluvarRiceMill/'
npm run build
npm run verify:site
npm run preview
```

Open the printed URL including `/ValluvarRiceMill/`. Remove those two
environment variables before returning to a root-hosted local preview.
